Spring Boot · Excel · Google Sheets · Gmail API

Gmail Draft Creator

Import contacts from Excel or selected Google Sheets tabs and create a separate personalized Gmail draft for each person. Every draft includes your resume attachment.

ⓘ
Drafts only. Nothing is sent.This app creates messages in your Gmail Drafts folder. Review each message in Gmail and click Send yourself. The app has no send-email endpoint or send action.
